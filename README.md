## Reader notes

The samples are updated as .NET and their dependencies evolve. Before following a chapter with newer tooling, check the [reader notes](docs/reader-notes/README.md) for changes to setup instructions, compatibility requirements, and known issues.

The [.NET 11 upgrade note](docs/reader-notes/dotnet-11.md) covers the current sample baseline and the Azure Functions build workaround for chapter 14.

The [domain entities in application responses note](docs/reader-notes/domain-entities-in-presentation.md) explains why presentation code should request cart changes through use cases, with examples of returning only the data a component needs.
